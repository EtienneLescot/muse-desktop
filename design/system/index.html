Contrôles natifs, libellés accessibles sur les icônes, focus bleu de 2 px, états accompagnés de texte et transitions courtes. Le réglage prefers-reduced-motion désactive les animations. Les modales se ferment avec Échap et conservent le focus dans le dialogue natif.
