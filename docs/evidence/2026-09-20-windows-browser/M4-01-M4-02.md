# Preuves navigateur intégré — M4-01 / M4-02 (20 septembre 2026)

Campagne CDP sur la version de développement, sidecar Muse Windows natif 1.3.0.
Complète le rapport [`2026-09-20-windows-group1`](../2026-09-20-windows-group1/README.md).

## Mode opératoire

```powershell
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS = "--remote-debugging-port=9222"
npm run tauri -- dev
node scripts/cdp-panel.mjs https://example.com/
```

## Le point qui bloquait

Les onglets de la barre de travail **n'existent pas dans le DOM tant que le panneau latéral est replié**. Le round 6 concluait à tort que la barre était inatteignable : l'inspection ne portait que sur une conversation au panneau fermé.

Sur une conversation ouverte, les sept onglets sont présents et détectables sans ouvrir le panneau :

**Content · Review · Terminal · Files · Browser · Desktop · Memory**

## M4-01 — navigateur intégré

| Contrôle | Observation |
|---|---|
| Champ d'adresse | `<input type="url">`, placeholder `https://example.com` |
| Navigation | URL posée via le setter natif, soumission par formulaire (`typed: true, via: form`) |
| **Rendu** | **une `iframe` est montée avec `src: https://example.com/`** |
| Persistance | `muse-desktop.browser.tabs.v1.session.b7c2faf4` → `[{"id":"tab-b2b3bd24-…","url":"https://example.com/","history":["https://example.com/"],"historyIndex":0}]` |
| **Isolation par session** | deux clés distinctes coexistent : `…session.b7c2faf4` (naviguée) et `…session.84bb6c78` (`url: ""`, `historyIndex: -1`). **Aucune traversée entre conversations.** |
| Contrôles disponibles | **Open native**, **Reload**, **Save selected link**, **Observe page**, **Capture visible**, bouton nouvel onglet (`+`) |

**Conclusion M4-01 :** la navigation, la persistance par onglet et l'isolation par `sessionId` sont **prouvées dans la webview native**. Le critère « qualification native multi-plateforme » reste ouvert (Windows seul observé), ainsi que les téléchargements initiés par navigation, qui ne font pas partie de cette passe.

## M4-02 — annotation

L'interface d'annotation est **présente et atteignable** dans le panneau Browser :

- champ `Text for selected field` (saisie vers un champ de la page) ;
- champ `Quoted selection (optional)` (citation de la sélection) ;
- champ `Comment (required)` (commentaire) ;
- actions **Add comment**, **Add page context**, **Observe page**, **Capture visible page**, **Click selected element**, **Navigate selected link**, **Open in new tab**, **Type into field**, **Save selected link**.

### Annotation réellement créée

Via `scripts/cdp-annotate.mjs`, une annotation a été rédigée puis enregistrée par l'action **Add comment**. L'état persistant est passé de `[]` à :

```json
[{"id":"3f629fe9-99f4-44ec-bf36-055bc78dea0c",
  "url":"https://example.com/",
  "selection":"example.com",
  "comment":"CDP annotation probe",
  "createdAt":1789907529662}]
```

**Établi :** création d'une annotation depuis la webview, **ancre URL normalisée** (`https://example.com/`), conservation de la **citation de sélection** et du **commentaire**, identifiant unique et horodatage. La persistance survit dans `muse-desktop.browser.annotations.v1`.

**Non établi :** la **garde de contexte après navigation** — c'est-à-dire qu'une note ancrée sur une page n'apparaisse pas sur une autre. Non exercé dans cette passe. Le recadrage de région et la capture visuelle ne sont pas non plus exercés.

## Libellé du panneau latéral

Le bouton qui replie le panneau est intitulé **« Hide work panel »** dans le DOM (et non un simple nom d'icône) — c'est le point d'entrée à utiliser pour l'ouvrir : les sept onglets n'existent qu'une fois le panneau déplié.

## Constat annexe — capacités refusées

La fin du corps de page expose un inventaire de permissions refusées : `browser denied`, `Allow finder denied`, `Allow terminal denied`, `Allow editor denied`, `Allow app`, ainsi que le message :

> **Image generation is not available in the in-app browser — it views pages and anchors comments only.**

C'est une confirmation directe de la politique M0-13 (« identifier clairement les capacités non connectées ») : le panneau annonce lui-même sa portée réelle au lieu de la simuler.

Le transcript expose aussi des libellés de contrôle de sous-agents — `subagent/interrupt`, `subagent/stop`, `subagent/resume`, `subagent/followupTask`, `subagent/readResult` — ainsi que `session/read`, ce qui documente la surface réellement câblée.
