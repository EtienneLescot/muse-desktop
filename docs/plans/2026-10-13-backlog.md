# Deferred backlog — 13 October 2026 (macOS closure)

Items deferred at the macOS closure of the [roadmap](../ROADMAP.md). Evidence is in
[`docs/evidence/2026-10-13-macos-closure/`](../evidence/2026-10-13-macos-closure/). The Windows
items of [6 October](2026-10-06-backlog.md) still stand.

All are low: none loses data or weakens security. The defects that did were fixed during the
campaign:
- `4fecdc8`: a project's posture followed through a symlinked folder; *Force remove* confirmed; an
  attached worktree protected;
- `df57377`: the test instance's computer-use relay isolated.

Each line ends with the reason it waits. Shared code is marked *(shared)*: it applies to Windows too.

## M0 — Recovery, policy and navigation

- **Settings' import box substitutes quotes on macOS.** A JSON snapshot typed there fails to parse.
  `3196ce2` turned substitution off in the composers and the terminal only. **Why deferred:** pasting
  works; only typed JSON is affected.
- **Stale reconnect text.** After a host crash, the open conversation reconnects by itself but still
  says "Reconnect to continue"; it reconnects automatically in one case and manually in another.
  *(shared)* **Why deferred:** wording; the 06/10 item covers the same text.
- **Stop without its turn id.** A Stop clicked about 100 ms after admission leaves without its
  `turnId`; the engine cancels the turn anyway. *(shared)* **Why deferred:** known fallback, the
  turn stops.
- **A silent engine** is detected only when `initialize` times out, about 121 s; the other
  incompatible engines are detected in 2.5 s. *(shared)* **Why deferred:** bounded, and the reason is
  shown.
- **Cmd+Enter on a question card** does not send after a choice made with the mouse: WebKit does not
  focus a clicked button. **Why deferred:** *Send answer* works.
- **Search** ignores case but not accents ("electricite" does not find "électricité"). *(shared)*
  **Why deferred:** not an M0-11 criterion.
- **"Ask only for more access"** says only what Windows does; the macOS 1.4.2 engine ran a shell
  script without asking. **Why deferred:** wording; the engine decides.
- **The *Workspace only* line** still reads "Writes stay inside the conversation's folder". The
  macOS exception is in the note above the levels. **Why deferred:** the limit is stated on the
  same screen.
- **The dictation note** does not name Apple's speech service on macOS. **Why deferred:** wording;
  the voice ticket (M4-08) waits for Étienne.

## M4 — Browser, documents, sharing, remote

  0.34.1 exists. **Why deferred:** driver; the model falls back on its own.

- **SSH session reset.** A host that accepts the key, then resets the session, gives "failed the MSP

- **Share publishing token.** It sits in clear in `localStorage`
  (`muse-desktop.share-endpoint.v1`), while MCP bearers go to the Keychain. *(shared)* **Why
  deferred:** same on Windows, local to the user's profile; *Forget* removes it. To harden.
- **Generic TLS failure message** ("Load failed"), with no word on the certificate. *(shared)*

- **Reference share server** listens on 0.0.0.0, with no option to choose the address. **Why

## Harness (macOS)

- **Bridge gaps.** It has no IME composition, no `DOM.setFileInputFiles`, no mouse wheel, no
  `Network.*`, no download control, and no script installed before a relaunched instance's first
  load. **Why deferred:** each proof states its workaround (DataTransfer, IPC answers, `textContent`).
- **IPC trace.** It keeps the last 400 calls only; proofs look calls up by time. **Why deferred:**
  enough for every proof.
- **Shared engine data root.** Test instances share the engine's data root: a model call to
  `add_memory` wrote into `~/.local/share/muse/memory` (removed after the M1-09 proof). **Why
  deferred:** the engine owns its data root (ADR 0003); proofs forbid tools when they can.
