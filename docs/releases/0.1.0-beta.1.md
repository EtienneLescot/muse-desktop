# Muse-Desktop 0.1.0-beta.1 — Windows x64

Première beta publique. **Non signée** : Windows affichera un avertissement SmartScreen (voir plus bas).

## Ce que cette beta fait

- Ouvrir l'application, **créer une conversation**, envoyer un message à un modèle, recevoir la réponse.
- **Retrouver ses conversations et ses projets** après fermeture et réouverture.
- Choisir un dossier de travail par conversation, avec héritage par projet.
- Lire un long historique sans ralentissement : la fenêtre du transcript est bornée, la recherche atteint les messages hors fenêtre.
- Naviguer au clavier (Tab sans piège, `Ctrl+F` pour la recherche), et utiliser l'interface avec les couleurs système forcées.

## Installation

1. Lancer `Muse-Desktop_0.1.0_x64-setup.exe`.
2. **Windows affichera un avertissement** — l'installateur n'est pas signé. Pour continuer : « Informations complémentaires » puis « Exécuter quand même ».
3. L'application s'installe dans `%LOCALAPPDATA%\Muse-Desktop` et ne demande **aucun droit administrateur**.
4. Au premier lancement, **choisir un dossier de travail** : sans dossier, la conversation ne peut pas démarrer.

## Configuration requise

- **Windows 10 ou 11, x64.**
- **Muse Code installé** — l'application pilote le moteur Muse, elle ne l'embarque pas pour son propre compte. Le sidecar est fourni avec l'installateur, mais l'authentification et la configuration du modèle viennent de Muse.
- WebView2 (fourni avec Windows 11, installé avec Windows 10 récent).

## Limites connues

- **Non signée** : avertissement SmartScreen au premier lancement.
- **Pas de mise à jour automatique en ligne** : une nouvelle version s'installe par-dessus l'ancienne, sans perte de données.
- **Windows uniquement** : aucune version macOS ni Linux dans cette beta.
- **Qualification d'accessibilité partielle** : le balisage et la navigation clavier sont vérifiés, mais l'application n'a **pas** été testée avec un lecteur d'écran réel.
- **Navigateur intégré** : navigation et annotations fonctionnent ; le recadrage de région et la capture visuelle ne sont pas livrés.
- **Sortie des commandes `userShell`** : le moteur reçoit le résultat, l'interface ne l'affiche pas encore — utiliser le repli qui insère la sortie dans le prompt.
- **Modèle et effort affichés** : l'interface montre le dernier modèle **demandé**, en le marquant comme non confirmé.
- **Reprise après la mort d'un host** : non garantie dans tous les cas.

## Ce que cette beta n'est pas

- Pas une version stable : des défauts existent, c'est le but d'une beta.
- Pas une version complète : plusieurs fonctions de l'interface existent sans être qualifiées.
- Pas une version signée.

## Rapporter un problème

Décrivez ce que vous faisiez, ce que vous attendiez, et ce qui s'est produit. Les journaux de l'application se trouvent dans `%LOCALAPPDATA%\com.muse.desktop`.
