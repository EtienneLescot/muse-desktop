# Muse-Desktop 0.1.0-beta.1 — Windows x64

First public beta. **Unsigned**: Windows will show a SmartScreen warning (see below).

## What this beta does

- Open the app, **create a conversation**, send a message to a model, get the answer.
- **Find conversations and projects again** after closing and reopening.
- Choose a working folder per conversation, with project inheritance.
- Read a long history without slowdown: the transcript window is bounded, and search reaches messages outside it.
- Navigate by keyboard (Tab with no trap, `Ctrl+F` for search), and use the interface with forced system colors.

## Install

1. Run `Muse-Desktop_0.1.0_x64-setup.exe`.
2. **Windows will show a warning** — the installer is not signed. To continue: *More info*, then *Run anyway*.
3. The app installs into `%LOCALAPPDATA%\Muse-Desktop` and asks for **no administrator rights**.
4. On first launch, **choose a working folder**: without one, the conversation cannot start.

## Requirements

- **Windows 10 or 11, x64.**
- **Muse Code installed** — the app drives the Muse engine, it does not bundle one of its own. The sidecar ships with the installer, but authentication and model configuration come from Muse.
- WebView2 (ships with Windows 11, installed with recent Windows 10).

## Known limits

- **Unsigned**: SmartScreen warning on first launch.
- **No online automatic updates**: a new version installs over the old one, without data loss.
- **Windows only**: no macOS or Linux build in this beta.
- **Partial accessibility qualification**: markup and keyboard navigation are verified, but the app has **not** been tested with a real screen reader.
- **Built-in browser**: navigation and annotations work; region cropping and visual capture are not shipped.
- **`userShell` command output**: the engine receives the result, the interface does not display it yet — use the fallback that inserts the output into the prompt.
- **Displayed model and effort**: the interface shows the last **requested** model, marked as unconfirmed.
- **Recovery after a host dies**: not guaranteed in every case.

## What this beta is not

- Not a stable version: defects exist, that is the point of a beta.
- Not a complete version: several interface functions exist without being qualified.
- Not a signed version.

## Reporting a problem

Say what you were doing, what you expected, and what happened. Application logs are in `%LOCALAPPDATA%\com.muse.desktop`.
