# Muse-Desktop 0.1.0-beta.2 — Windows x64

Second beta. **Unsigned**: Windows will show a SmartScreen warning (see below).
First version built and published by GitHub CI.

## New since beta 1

- **Computer use**: Muse can see the screen and, if you allow it, drive Windows applications,
  through the open-source [cua driver](https://github.com/trycua/cua) (installed separately). Two
  levels in Settings: **Observe only** (screenshots and window reading, no clicks, no typing) and
  **Observe and act** (mouse, keyboard, clipboard).
- **A more readable thread**: Markdown answers (tables, code blocks with a Copy button), tool calls
  visible live then folded into one line ("12 steps · 49s"), a "Stopped" note when a turn is
  stopped.
- **More than 32 conversations per folder**: when the engine reaches its limit of 32 loaded
  conversations, the app makes room instead of failing (unless a conversation is working). A
  conversation is resumed when you open it.
- **Composer**: model choice from the welcome screen, a context usage meter (one click compacts the
  conversation), effort aligned with the Muse Spark levels.
- **Rebuilt built-in browser**: tabs, back, forward, reload, address bar, and opening in a window
  for sites that refuse to be embedded.
- **Worktrees**: start a conversation in a worktree, or move a conversation into one.
- **Sub-agents**: close, reopen and follow their real status.
- **Sign in to Muse from Settings**, with a warning when an API key masks the sign-in.
- **Terminal**: it starts in the conversation's folder.
- **Housekeeping**: panels and settings with no real function have been removed.

## Install

1. Run `Muse-Desktop_0.1.0-beta.2_x64-setup.exe`.
2. **Windows will show a warning** — the installer is not signed. To continue: *More info*, then
   *Run anyway*.
3. The app installs into `%LOCALAPPDATA%\Muse-Desktop`, over beta 1 if present, and asks for **no
   administrator rights**.
4. On first launch, **choose a working folder**.

## Requirements

- **Windows 10 or 11, x64.**
- **Muse Code installed**: authentication and model configuration come from Muse.
- WebView2 (ships with Windows 11, installed with recent Windows 10).
- For computer use: **cua-driver** (MIT). The install command is shown in Settings.

## Known limits

- **Unsigned**: SmartScreen warning on first launch.
- **No automatic updates**: a new version installs over the old one.
- **Windows only.**
- **"Observe and act" has no limit on the driver side**: your consent in Settings is the only
  barrier. Turn that level on only while you need it.
- **Model shell commands**: under the engine's Windows sandbox, the model's PowerShell tool may
  never return (a Muse engine defect). File tools work, and the Stop button interrupts the stuck
  tool.
- **Accessibility**: keyboard navigation verified, **no** test with a real screen reader.

## Reporting a problem

Say what you were doing, what you expected, and what happened. Application logs are in
`%LOCALAPPDATA%\com.muse.desktop`.
