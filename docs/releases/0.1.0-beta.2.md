# Muse-Desktop 0.1.0-beta.2 — Windows x64

Deuxième beta. **Non signée** : Windows affichera un avertissement SmartScreen (voir plus bas).
Première version construite et publiée par la CI GitHub.

## Nouveautés depuis la beta 1

- **Utilisation de l'ordinateur** : Muse peut voir l'écran et, si vous l'y autorisez, piloter les
  applications Windows, via le driver open-source [CUA](https://github.com/trycua/cua) (à installer
  à part). Deux niveaux dans les Réglages : **Observe only** (captures et lecture des fenêtres,
  sans clic ni frappe) et **Observe and act** (souris, clavier, presse-papiers).
- **Un fil plus lisible** : réponses en Markdown (tableaux, blocs de code avec bouton Copier), appels
  d'outils visibles en direct puis repliés en une ligne (« 12 steps · 49s »), note « Stopped »
  quand un tour est arrêté.
- **Plus de 32 conversations par dossier** : quand le moteur a atteint sa limite de 32
  conversations chargées, l'app libère la place au lieu d'échouer (sauf si une conversation est en
  train de travailler). Une conversation est reprise quand on l'ouvre.
- **Composeur** : choix du modèle dès l'écran d'accueil, indicateur d'utilisation du contexte (un
  clic compacte la conversation), effort aligné sur les niveaux de Muse Spark.
- **Navigateur intégré refait** : onglets, précédent, suivant, recharger, barre d'adresse, et
  ouverture dans une fenêtre pour les sites qui refusent d'être intégrés.
- **Worktrees** : démarrer une conversation dans un worktree, ou y déplacer une conversation.
- **Sous-agents** : fermer, rouvrir et suivre leur statut réel.
- **Connexion à Muse depuis les Réglages**, avec une alerte quand une clé API masque la connexion.
- **Terminal** : il démarre dans le dossier de la conversation.
- **Ménage** : les panneaux et réglages qui n'avaient pas de fonction réelle ont été retirés.

## Installation

1. Lancer `Muse-Desktop_0.1.0-beta.2_x64-setup.exe`.
2. **Windows affichera un avertissement** — l'installateur n'est pas signé. Pour continuer :
   « Informations complémentaires » puis « Exécuter quand même ».
3. L'application s'installe dans `%LOCALAPPDATA%\Muse-Desktop`, par-dessus la beta 1 le cas
   échéant, et ne demande **aucun droit administrateur**.
4. Au premier lancement, **choisir un dossier de travail**.

## Configuration requise

- **Windows 10 ou 11, x64.**
- **Muse Code installé** : l'authentification et la configuration du modèle viennent de Muse.
- WebView2 (fourni avec Windows 11, installé avec Windows 10 récent).
- Pour l'utilisation de l'ordinateur : **cua-driver** (MIT). La commande d'installation est
  affichée dans les Réglages.

## Limites connues

- **Non signée** : avertissement SmartScreen au premier lancement.
- **Pas de mise à jour automatique** : une nouvelle version s'installe par-dessus l'ancienne.
- **Windows uniquement.**
- **« Observe and act » n'a pas de limite côté driver** : votre accord dans les Réglages est la
  seule barrière. N'activez ce niveau que pendant que vous en avez besoin.
- **Commandes shell du modèle** : sous la sandbox Windows du moteur, l'outil PowerShell du modèle
  peut ne jamais revenir (défaut du moteur Muse). Les outils de fichiers fonctionnent, et le
  bouton Stop interrompt l'outil bloqué.
- **Accessibilité** : navigation clavier vérifiée, **pas** de test avec un lecteur d'écran réel.

## Rapporter un problème

Décrivez ce que vous faisiez, ce que vous attendiez, et ce qui s'est produit. Les journaux de
l'application se trouvent dans `%LOCALAPPDATA%\com.muse.desktop`.

## Vérifier le paquet

Les sommes de contrôle SHA-256 de l'installateur et du moteur Muse qu'il embarque sont publiées
dans `Muse-Desktop_0.1.0-beta.2_x64-setup.manifest.json`, à côté de l'installateur.
