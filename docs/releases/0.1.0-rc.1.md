# Muse-Desktop 0.1.0-rc.1 — Windows x64, macOS Apple Silicon

Release candidate for the first stable version. It is the same code as
[0.1.0](0.1.0.md) apart from the version number, built by the same chain, and
its notes described the same product.

Read [the 0.1.0 notes](0.1.0.md) instead: what the app does, both platforms,
what was verified before shipping, install steps, requirements and known limits.

Two things landed in this candidate and carried into 0.1.0:

- **macOS became a supported platform**, with a DMG signed and notarised by
  Apple, so there is no Gatekeeper warning.
- The Windows installer stayed unsigned.

The published GitHub release for this tag keeps its original notes.
