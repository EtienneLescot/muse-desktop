# Muse-Desktop 0.4.1 — macOS Apple Silicon, Windows x64

A naming release. The app now shows itself as **MuDesktop**: the Microsoft Store refused a product
name that contained another product's name (policy 10.1.1.1), and the app's own window should match
its Store listing. Nothing else changes from [0.4.0](0.4.0.md).

The app holds no agent logic. It drives the `muse` engine, which stays the only source of
authentication, models and tools. MuDesktop is an independent app for Muse Code; it is not made,
endorsed or supported by Meta.

## Changes since 0.4.0

- **MuDesktop** in the sidebar, the window title, the loading screen and the setup messages.
- **Microsoft Store package.** The release workflow builds the Store MSIX under the name MuDesktop.
- **Unchanged on purpose.** Installer file names, the install folder and the app's name in macOS
  privacy settings stay "Muse-Desktop", so 0.4.1 installs over 0.4.0 with no loss, and existing
  scheduled-run wake-up tasks keep working.

Platforms, requirements, known limits and verification are as in [0.4.0](0.4.0.md).

## Verifying the package

SHA-256 checksums for the Windows installer and the engine it bundles are published in
`Muse-Desktop_0.4.1_x64-setup.manifest.json`, next to the installer. The macOS DMG is verifiable
through its Apple signature:

```sh
spctl -a -t open --context context:primary-signature -vv Muse-Desktop_0.4.1_aarch64.dmg
```
