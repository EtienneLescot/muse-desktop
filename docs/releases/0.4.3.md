# Muse-Desktop 0.4.3 — macOS Apple Silicon, Windows x64

Fixes from the first days of MuDesktop on the Microsoft Store, on every platform.

The app holds no agent logic. It drives the `muse` engine, which stays the only source of
authentication, models and tools. MuDesktop is an independent app for Muse Code; it is not made,
endorsed or supported by Meta.

## Fixed

- **Links in the agent's answers open.** A file the agent names (`review.md`, `src/app.ts:12`) opens
  in the Files panel with its preview; a web link opens in your browser. Before, a click did
  nothing. Links to files outside the conversation's folder are not followed.
- **The model picker works in a new conversation.** It now shows the conversation's model and lists
  the engine's catalog; before, it read "Model" and opened empty until you switched conversations.
  On the empty screen the picker stays visible ("Default model") until a first engine has run,
  instead of disappearing.
- **The file preview stays open** when the Files panel refreshes its folder (every 30 seconds, and
  right after a link opened a file).

The model list is the one the Muse engine offers your account: with a single model in its catalog,
the picker has a single choice.

Platforms, requirements, known limits and verification are as in [0.4.0](0.4.0.md).

## Verifying the package

SHA-256 checksums for the Windows installer and the engine it bundles are published in
`Muse-Desktop_0.4.3_x64-setup.manifest.json`, next to the installer. The macOS DMG is verifiable
through its Apple signature:

```sh
spctl -a -t open --context context:primary-signature -vv Muse-Desktop_0.4.3_aarch64.dmg
```
